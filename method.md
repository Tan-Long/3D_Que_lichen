To quantify lichen covarage on cassia bark surface, the analysis pipeline begins with field data acquisition using a LiDAR-equipped mobile device (iPhone 12+ Pro/Pro Max). The integration of consumer-grade LiDAR in these devices has been validated as a reliable, cost-effective tool for capturing high-resolution 3D point clouds in forest inventories (Gollob et al., 2021) and broader geoscientific applications (Luetzenburg et al., 2021). For lichen detection, the algorithm evaluated local contrast and color saturation within the Hue, Saturation, Value (HSV) spaced directly on the raw point cloud - a robust approach for color-based segmentation under varying outdoor lighting conditions (Cheng et al., 2001). The system employed adaptive thresholds based on natural bark reflectance to accurately isolate lichen colonies and filter out green vegetation. These classification labels were then mapped onto the finalized mesh. By calculating the physical area of each mesh triangle and determining the trunk’s primary axis via Principal Component Analysis (PCA) (Pfeifer et al., 2004), the system quantified total coverage. To classify spatial orientation, the empirical global gravity vector (aligned to the world Y-axis) was projected onto a plane perpendicular to the trunk axis to establish the “upslope” direction. By evaluating each mesh face’s centroid against this directional vector, the system precisely categorized and reported lichen distribution across the upslope and downslope sides of the tree.
